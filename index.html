Import from PrizePicks

Paste your entry history — there’s nothing to fetch

PrizePicks keeps entry history behind your login and publishes no per-account API, so there’s no address to point at the way Polymarket has. Paste it instead, in whichever of these you can get.

Copy straight out of Excel, Numbers or Google Sheets — tabs, commas and semicolons all parse. A header row is detected and matched on names, so column order doesn’t matter; without one, the order below is assumed.

returned is only needed for a flex play that part-hits — leave it blank otherwise. result accepts win / loss / push / partial / pending and the obvious synonyms; leave it blank and it’s inferred from what came back. multiplier takes 3, 3x or American odds like +150.

Log in to PrizePicks in a desktop browser, open your entry history, and in DevTools → Network click the request that returns it — Copy → Copy response — then paste it here. Nothing leaves this page, and you never handle a token: your browser is already signed in.

Stakes, multipliers, results and dates come across. Pick-level detail varies by payload, so an entry may land as its type and pick count — rename any of them afterwards like a hand-logged bet.

Import from Polymarket

Reads your public trade history and turns each market into a bet

Set this book’s starting bankroll above first — imported bets are sized in units against it.

The address in your profile URL — polymarket.com/profile/0x…. That’s your proxy wallet. Public read-only data: no keys, no signing, nothing that can move funds.

Fetching works when this page can reach polymarket.com directly — opening index.html from your own machine. On claude.ai the page is sandboxed and can’t call other sites, so use Paste JSON; it produces exactly the same import.

Open each link, copy the whole response, paste it in the matching box

Paste both if you can. A market you lost leaves no trade when it resolves — the position just disappears — so the positions list is how those get booked as losses instead of sitting open forever. Paste an empty [] if you genuinely hold nothing.
